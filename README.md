# FrenchNumbers

Тренажёр для французских числительных от 1 до 100 с заданиями на распознавание и написание.

## Live

- GitHub Pages: <https://polpal1623.github.io/FrenchNumbers/>
- Репозиторий: <https://github.com/PolPal1623/FrenchNumbers>

## Что внутри

- 8 случайных раундов из словаря чисел 1-100.
- Два режима: число в слова и слово в число.
- Мягкая проверка орфографии для французского ввода.
- IPA, русская транскрипция и итоговая статистика по времени.
- Переключение темы и адаптивный интерфейс.

## Запуск

1. Откройте `index.html` в браузере.
2. Сборка, сервер и зависимости не нужны.

## Редактирование

- Словарь хранится в массиве `numberDictionary`.
- Длину сессии задаёт константа `TOTAL_ROUNDS`.
- Все стили и логика находятся в одном файле.
